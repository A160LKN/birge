# Чек-листы ручной проверки «Бірге»

Ручная проверка дополняет автотесты там, где важен глаз человека: внешний вид, удобство, реальные устройства и живой сайт с настоящей инфраструктурой. Для проверок вдвоём откройте два разных браузера (или обычное и приватное окно) и войдите как `aliya@birge.kz` и `bauyrzhan@birge.kz`, пароль `birge-demo`.

## Смоук после деплоя — 5 минут

Проходится на живом сайте после каждого изменения бэкенда, фронтенда или настроек хостинга.

- [ ] `/health` на API отвечает `{"status":"ok"}` (первый запрос может идти до минуты — сервер просыпается)
- [ ] Вход работает, список досок открывается
- [ ] Доска открывается, в шапке статус «в сети» и аватары тех, кто на доске
- [ ] Алия создаёт карточку — у Бауыржана она появляется без обновления страницы
- [ ] Бауыржан переносит карточку — у Алии она переезжает и подсвечивается его цветом
- [ ] Комментарий и вложение-картинка добавляются, превью появляется через несколько секунд
- [ ] Выгрузка CSV готовится, файл скачивается и открывается

## Регресс перед релизом

### Доски и участники

- [ ] Новая доска создаётся с тремя колонками
- [ ] Владелец приглашает участника по email; участник видит доску в своём списке
- [ ] Участник не видит поле приглашения и не может удалить других
- [ ] Удалённого участника сразу выводит с доски, его карточки остаются без исполнителя
- [ ] Чужая доска по прямой ссылке — «доска не найдена», а не ошибка доступа
- [ ] Переименование и удаление доски доступны только владельцу

### Колонки и карточки

- [ ] Колонку можно добавить, переименовать, сдвинуть и удалить через меню
- [ ] Последнюю колонку удалить нельзя; при удалении колонки удаляются её карточки
- [ ] Карточка перетаскивается мышью внутри колонки и между колонками
- [ ] Карточка перетаскивается с клавиатуры (пробел — взять, стрелки — двигать, пробел — отпустить)
- [ ] Карточка, отпущенная на прежнее место, не отправляет запрос (вкладка Network пустая)
- [ ] Исполнитель, срок, описание сохраняются; очистка исполнителя и срока работает
- [ ] Ссылка `?card=` открывает карточку с обсуждением

### Одновременная работа

- [ ] Двое правят описание одной карточки — второй видит экран конфликта с сохранённой версией и выбирает, что оставить
- [ ] Один правит описание, другой в это время переносит ту же карточку — конфликта нет
- [ ] Выключите Wi-Fi на 30 секунд, пока коллега что-то меняет, и включите обратно — пропущенные изменения появляются без перезагрузки
- [ ] Своё изменение из этой же вкладки не подсвечивается как чужое

### Файлы и выгрузка

- [ ] Картинка JPG/PNG/WebP/GIF загружается, превью становится обложкой карточки
- [ ] Файл больше 5 МБ не отправляется, текст ошибки понятный
- [ ] `.exe`, `.html` и картинка с подменённым расширением не принимаются
- [ ] Имя файла на кириллице сохраняется при скачивании
- [ ] В CSV время изменения — по Астане, ячейки с `=`, `+`, `-`, `@` в начале не превращаются в формулы в Excel

## Телефон

Safari на iPhone и Chrome на Android.

- [ ] Колонки листаются по горизонтали, страница целиком вбок не сдвигается
- [ ] Карточка открывается на весь экран и закрывается
- [ ] Перетаскивание пальцем работает, прокрутка колонок при этом не срабатывает случайно
- [ ] Поля ввода не увеличивают страницу при фокусе
- [ ] Тёмная тема переключается и сохраняется

## Доступность

- [ ] Вся доска проходима с клавиатуры, фокус виден
- [ ] Экранный диктор (VoiceOver) объявляет перенос карточки
- [ ] Контраст текста достаточен в обеих темах
- [ ] Интерфейс читаем при увеличении шрифта браузера до 200 %
