# Безопасность

## Как сообщить об уязвимости

Если вы нашли уязвимость в Бірге, не создавайте публичный Issue. Напишите на **aibolkazbayev@gmail.com** с темой «Бірге security»: что нашли, как воспроизвести, чем это грозит. Отвечу в течение трёх дней.

## Что сделано

- Пароли — scrypt с солью; слабые и популярные пароли не принимаются; пароль проверяется и для несуществующего email — по времени ответа не узнать, кто зарегистрирован.
- 5 неудачных входов за 15 минут на пару «email + IP» → 429 с `Retry-After`; второй рубеж — 20 попыток на один email с любых адресов. Регистрация — 10 в час с одного IP.
- Заголовки безопасности: на API — CSP, HSTS, X-Frame-Options, nosniff, Referrer-Policy; на сайте (Vercel) — строгая CSP без inline-скриптов.
- Доступ к доскам — только участникам; вложения отдаются по подписанным ссылкам с ограниченным сроком.
- WebSocket: токен проверяется первым сообщением с таймаутом, чужую доску не открыть.
- Тело запроса ограничено размером вложения; ошибки 500 без подробностей, только ID запроса.
- Каждый CI: pip-audit и npm audit (уязвимые зависимости), CodeQL (анализ кода), axe (доступность).
- Тесты: `backend/tests/api/test_hardening.py`, `frontend/e2e/a11y.spec.ts`.
